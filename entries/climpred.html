climpred (decadal prediction verification)

Fixed – not yet releasedcodeSignificance: Medium

What it is

climpred is a Python package for verifying initialized decadal and seasonal climate predictions, including comparing them with uninitialized (free-running) model simulations.

Finding

Uninitialized reference uses single-member skill, overstating the value of initialization; bootstrap false positives 68–73%

VerdictReal error
SignificanceMedium (Size 2 · Reach 1 · Consequence 1 = 4 of 6)
Basis: Bootstrap false positives 68-73% (S); standard decadal-verification package (R); merged, no rerun (C)
OutcomeFixed – not yet released
Fixed on2026-11-09
Fixed inPR #970 (merged 9 Nov 2026)
Affected versionsv2.6.0 and earlier (first affected version not checked)
