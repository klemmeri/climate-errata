climate_indices (SPI, Pearson III)

Fixed – not yet releasedcodeSignificance: Medium

What it is

climate_indices is a Python package that computes drought indices such as the Standardized Precipitation Index (SPI), which expresses rainfall over a period as a number of standard deviations from normal.

Finding

Zero-rain months counted twice in SPI

VerdictReal error
SignificanceMedium (Size 1 · Reach 1 · Consequence 1 = 3 of 6)
Basis: Zero-rain months double-counted shifts SPI in dry months (S); widely used SPI package (R, est.); fixed, papers not rerun (C)
OutcomeFixed – not yet released
Fixed on2026-11-05
Fixed inPR #1563 (merged 5 Nov 2026; milestone v3.2.1)
Affected versionsv3.2.0 and earlier (first affected version not checked)
Is the fix retroactive?Fix merged but not yet in a release. Results from all released versions are still affected; install from the main branch or wait for the next release.
Where reportedGitHub #1562
