Hamed–Rao test default (pyMannKendall, modifiedmk)

Reported (open)codeSignificance: Medium

What it is

The Hamed–Rao test is a version of the Mann–Kendall trend test that inflates the test's variance to allow for autocorrelation. It is implemented in pyMannKendall and modifiedmk.

Finding

About 2× the nominal false-positive rate on white noise

VerdictReal error (partly the method)
SignificanceMedium (Size 1 · Reach 2 · Consequence 1 = 4 of 6)
Basis: About 2x nominal false-positive rate (S); default test in pyMannKendall/modifiedmk (R); no rerun (C)
