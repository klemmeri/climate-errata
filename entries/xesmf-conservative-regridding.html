xESMF conservative regridding

Fixed – not yet releasedcodeSignificance: High

What it is

xESMF is a Python package for regridding (interpolating) climate data between grids. Conservative regridding is meant to preserve totals such as rainfall or energy.

Finding

Polar rows corrupted for pole-centered grids (ERA5, MERRA-2, JRA-55)

Summary

xESMF is the standard Python regridder for climate and reanalysis data, and "conservative" is the method recommended for precipitation and fluxes. When the input has no cell-bound variables (the usual case for ERA5 from the Climate Data Store, NCEP R1/R2, MERRA-2 and JRA-55), xESMF infers bounds that run past ±90°. ESMF then computes wrong weights for the polar rows. A constant 280 K field regridded from ERA5 comes out as 293 K in the rows at ±89.5°.

What we found

Polar-row values after conservative regridding of a smooth test field, against exact spherical weights (correct value about 280 K):

Source → targetPolar rowCap mean north of 80°N
ERA5 0.25° → 1°293 K (+15 K, about 5%)+0.13 K
ERA5 1° → 2.5°314 K+2.1 K
MERRA-2 0.5° × 0.625° → 1°333 K+0.53 K
JRA-55 1.25° → 2.5°333 K+3.3 K
NCEP 2.5° → 1°about 1,400 K+13.2 K
1° → NCEP 2.5° (pole-centered target)140 K (halved)−1.7 K
  • The error multiplies the polar rows, so it affects absolute values, precipitation and anomalies alike. Global means are off by only 0.002–0.2 K.
  • For ERA5 at 0.25°, the most common input, the error is about 5%: plausible enough to go unnoticed. The only signal is a generic warning, "Latitude is outside of [-90, 90]".
  • Grids without pole points (−89.5 … 89.5) are not affected. xcdat already clips its own bounds to ±90°, so xcdat users are safe.
  • Users had reported the symptom before (xESMF discussions #325 and #177); the cause and a fix had not been identified.

Response

Reported as xESMF #497 with a fix in PR #498, which clips inferred latitude bounds to [−90, 90] and adds a constant-field test. Merged 16 November 2026; not yet in a release.

What users can do

Until a release includes the fix: supply latitude bounds clipped to ±90° (errors fall to ≤ 0.01 K), or use conservative_normed (≤ 0.18 K). Check polar rows in existing regridded output from pole-centered grids.
