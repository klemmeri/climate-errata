martinvonk/SPEI (Python)

Reported (open)codeSignificance: Low

What it is

martinvonk/SPEI is a Python package for computing standardized drought indices (SPI, SPEI) from rainfall and evaporation series.

Finding

prob_zero=True counts zeros twice, biasing SPI high

VerdictReal error
SignificanceLow (Size 1 · Reach 0 · Consequence 1 = 2 of 6)
Basis: Zeros double-counted biases SPI high in dry months (S); Python SPEI package (R, est.); no rerun (C); reconciled: R0, non-default prob_zero option of a small package
OutcomeOpen
