modifiedmk (R) mmky()

ConfirmedcodeSignificance: Medium

What it is

modifiedmk is an R package of Mann–Kendall trend tests modified for serially correlated data. Its mmky() function implements the Yue–Wang variance correction.

Finding

Same all-lags flaw since v1.1.0 (2018)

VerdictReal error (partly known)
SignificanceMedium (Size 2 · Reach 1 · Consequence 1 = 4 of 6)
Basis: Same all-lags flaw: false positives several times nominal (S); R package in hydrology (R); maintainer agreed, no rerun (C)
OutcomeConfirmed
Where reportedGitHub #4 + PR #5
