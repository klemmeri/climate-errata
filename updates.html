Site updates

Changes to the Climate Errata website itself: new features, new pages and changes to how it works. Updates to the errata are in the register and its feed.

RSS feed of site updates · Suggestions for the site are welcome through Write to us.

New address: climateerrata.org

2026-11-22

The site now lives at climateerrata.org. The old address, climate-errata.netlify.app, redirects there automatically, so existing links keep working.

Full write-ups for the High-significance entries

2026-11-22

The 11 entries rated High significance now have full write-ups: what was found, with the key numbers, who is affected, the responsible party's response, what users can do, and how to reproduce the result. The other entries will follow.

Fix details on every fixed entry

2026-11-22

Each fixed entry now shows when the fix was made, which version or pull request contains it, which versions are affected, and whether the fix is retroactive. The register separates fixes that are released from fixes merged but not yet released. Release statuses were rechecked on GitHub and CRAN.

Policies and privacy page

2026-11-22

A new page covers contact first, author responses and disputes, corrections and withdrawals, moderation, a code of conduct, funding and conflicts of interest, use of AI, privacy, and takedown or legal requests. It is linked from the top menu and every page footer.

Papers that use the affected data

2026-11-22

Entries about a problem in a dataset can now list papers that use the affected data for the affected region and period. The effect on each paper is not assessed. The first lists are on the MERRA-2 Australia and ASOS wind entries.

Dataset pages

2026-11-22

A new Datasets section has one page for each of 14 widely used datasets (ERA5, MERRA-2, CPC Unified, GPCC, GPCP, IMERG, E-OBS, ICOADS, HadSST4, OISST, IBTrACS, COOP HPD, ASOS, GHCN-CAMS). Each page gives the current version, the producer's known-issues page and contact, our entries, related discussions, a place to ask questions, and an RSS feed. There is also a feed for the whole register.

Discussion by DOI, site search and a contact form

2026-11-22

Any paper or dataset can now have a discussion page: enter its DOI on Discuss a DOI. Search covers the register, the datasets and the discussions. Write to us takes questions, private error reports and author responses from people without a GitHub account. A posting policy asks that new error claims go to the responsible party first.

Climate Errata launched

2026-11-22

The register of errors found in climate papers, datasets and code moved from its earlier home to this site, with 48 entries, filters, a significance rubric and a comment thread on every entry.
